Lawyers are often asked to review a system after it is built. A short set of questions, asked early, finds most of the problems that would otherwise surface later.

## Five questions

1. What personal data does the system collect, and is each item needed?
2. Who can see it, and how is that access recorded?
3. How long is it kept, and what triggers deletion?
4. Can a person ask what is held about them, and who answers?
5. What happens to the data if a supplier changes or disappears?

## Using the list

The value of a checklist is that it makes silence visible. If nobody can answer a question, that is the finding.
